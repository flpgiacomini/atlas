# ATLAS — What A9 Means and What Comes After

## A6 — Functional MVP
The first custom exploration experience, if custom software is actually needed.

At this stage the concept works, but coverage and polish are limited.

## A7 — Content MVP
Enough globally varied content exists to validate actual use, not only technical navigation.

## A8 — Architecture Gate
The project decides what infrastructure should survive long term.

## A9 — Atlas v1.0 / Product Complete
A9 is **not just a prototype**.

At A9:
- research workflow works;
- canonical data model is stable;
- source/evidence handling works;
- data is portable/backed up;
- ingestion process is defined;
- search works;
- entity pages work;
- relation exploration works;
- timeline works;
- map works;
- graph/genealogy works;
- comparison works at the intended v1 level;
- a meaningful global corpus exists;
- the Atlas is useful for real personal exploration.

This is the end of the initial product implementation roadmap.

## Why A9 cannot mean “100% complete forever”
The Atlas is an open-ended historical knowledge project.

Even if the software stopped changing after A9:
- more vehicles can be added;
- new historical sources can appear;
- errors can be corrected;
- manufacturers can change ownership;
- new vehicles are announced;
- future events become historical events;
- additional regions and obscure manufacturers can be researched.

Therefore content completeness has no final 100% state.

## Post-A9 lifecycle

### V1.x — Content & Quality
Primary focus:
- expand entities;
- deepen weak areas;
- resolve disputed Claims;
- improve source quality;
- improve search/discovery;
- minor UX refinements.

### V2 Gate — Major capability review
Only consider major features after sustained real use.

Potential examples:
- advanced temporal “industry at year X” exploration;
- richer comparison;
- more powerful graph traversal;
- automated source-monitoring;
- AI-assisted extraction with human approval;
- historical map layers;
- public/shared version if ever desired.

### V2+ — Optional
No obligation to build it.

A9 should be a point where the user can reasonably say:
> “The Atlas exists and does what I originally wanted.”

Everything afterward is evolution, not unfinished foundational work.
