# CP17 — progresso 03: industrialização global, 1938–1968

Data de verificação: 2026-08-24

## Resultado

O terceiro lote resolve 17 dos 20 capítulos interativos examinados e, por
validade compartilhada, acrescenta 18 anos à cobertura global. O indicador
passa de 29/98 para **47/98**; o backlog cai de 69 para **51**.

O acervo alcança 54 features em 21 coleções GeoJSON, cobrindo Koromo, Rouge,
Wolfsburg, o fluxo Detroit–Melbourne, Maranello, Gmünd, Coventry–Le Mans,
Stuttgart–Nova York, exportação do Crown, Longbridge, Gotemburgo,
Coventry–Genebra, Dearborn–Nova York, Frankfurt e Washington.

## Lacunas preservadas

- **1950:** a entidade de transferência tecnológica possui evidência espacial
  a partir de 1951, mas não uma geometria material sustentada para 1950;
- **1956:** os marcos documentados de mobilidade e segurança começam em 1957;
- **1960:** as evidências espaciais do conjunto de design e desempenho começam
  com o E-Type em 1961.

Esses anos permanecem `pending`. O Atlas não estende retroativamente uma
geometria apenas para fechar o contador.

## Decisões de integridade

- Longbridge e Gotemburgo são features separadas, cada qual com sua fonte;
- a EPA sustenta o marco de emissões, não uma alegação genérica de segurança;
- fluxos transatlânticos são editoriais e aproximados;
- uma fábrica ou cidade mapeada não representa automaticamente todos os lugares
  citados por um capítulo multientidade.
