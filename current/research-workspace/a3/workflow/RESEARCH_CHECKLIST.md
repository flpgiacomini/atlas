# Atlas Research Checklist v1.0

For one new research subject:

## Discover
- [ ] Identify candidate entity/topic.
- [ ] Check Atlas for existing identity.
- [ ] Capture useful sources in Zotero.

## Resolve
- [ ] Confirm entity type.
- [ ] Check external IDs.
- [ ] Reconcile ambiguous names if needed.
- [ ] Avoid duplicate Atlas entity creation.

## Curate
- [ ] Create/update Entity.
- [ ] Add only historically useful Statements.
- [ ] Use existing Predicate where possible.
- [ ] Preserve date precision.
- [ ] Add Event only when an occurrence matters historically.

## Evidence
- [ ] Attach Source.
- [ ] Record Evidence locator.
- [ ] Set Claim stance/support strength.
- [ ] Set Statement confidence/resolution.
- [ ] Preserve disagreements rather than flattening them.

## Connect
- [ ] Add relevant genealogy.
- [ ] Add people/organization/technology/place connections.
- [ ] Add Motorsport Entry only when applicable.

## Review
- [ ] Can the entity be understood without opening every source?
- [ ] Can a user navigate somewhere meaningful from it?
- [ ] Did we add detail that does not improve understanding?
- [ ] Does any new type/predicate appear necessary? If yes, challenge it before adding.

## Export
Periodically export workspace data and validate against Atlas SQLite schema.
