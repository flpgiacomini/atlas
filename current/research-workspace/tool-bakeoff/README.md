# ATLAS Tool Bake-Off v0.2

This package contains the evidence-based pre-selection and import mappings for:
- Heurist
- Wikibase
- nodegoat

It also contains:
- tool scorecard;
- supporting-tools shortlist;
- import-ready flattened CSVs generated from the five-case canonical SQLite snapshot.

The package does not change the Atlas canonical authority.
During A1/A2 the canonical test dataset remains SQLite + CSV.
