# Segurança

Não publique vulnerabilidades ou credenciais em issues. Comunique problemas de
segurança diretamente ao mantenedor pelo endereço associado ao perfil GitHub
`flpgiacomini`.

O produto é estático e não recebe credenciais em runtime. Tokens de GitHub e
acessos temporários do Heurist devem existir somente nos mecanismos seguros dos
respectivos provedores. O banco publicado contém apenas conhecimento destinado
à distribuição pública.
